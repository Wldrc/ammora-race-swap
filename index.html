How it works

Quotes come from the live pool (quoteExactIn via the SDK's arlV5PoolAbi). Swaps are one native-ETH transaction to Ammora's V5 native router — calldata built by the SDK (buildV3NativePoolExactInput, swapPoolExactInNative). The V5 deployment manifest (factory, implementation, fee controller, fee vault, token policy, fee policy) is pinned by runtime code hash and re-verified on-chain by the SDK (ArlV5FactoryClient.verifyDeploymentAtBlock / verifyPoolAtBlock) on every load. No private key is ever stored or sent anywhere; your wallet signs everything.
